# cursos-
Plataforma para cursos online.

## Cómo ejecutarlo

1. Clona el repositorio:
   ```bash
   git clone https://github.com/MtroErikTimal/cursos-.git
   cd cursos-
   ```
2. Sirve la carpeta con un servidor HTTP sin necesidad de backend:
   ```bash
   python3 -m http.server 8000
   ```
3. Abre en tu navegador:
   ```text
   http://localhost:8000/index.html
   ```
